# The Floor — Picture Challenge

A two-player picture game show you play in the browser. Open `index.html` to start.

## How to play
- Pick a topic and press **Start game**.
- Each player has their own clock. Name what's on screen before your time runs out.
- The order of the pictures is random every game.

## Keys
| Key | Action |
|-----|--------|
| ← Left arrow | They got it right |
| → Right arrow | Pass |
| Space | Pause / resume |
| D | Peek at the answer (host only) |

## Topics
Desserts, Food, Flags, Movies, Cartoon Characters, Anime Characters, Football Players, Celebrities, Acronyms. There are 100 items in each.

Pictures load from the internet (Wikipedia, Wikimedia Commons and fan wikis). If a picture doesn't load, the game skips it.
